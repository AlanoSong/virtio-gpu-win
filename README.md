# VirtIO GPU Windows Driver
- According to windows WDDM & DirectX spec, the GPU driver consists of KMD(kernel mode driver) and UMD(user mode driver)
- In this project, KMD corresponding to `viogpu3d`, and UMD corresponding to `d3d10umd`

## Prebuild
- Install Visual Studio under real/virtual windows system.
- Install corresponding windows WDK develop kit.
- Then we will get all the develop enviroment we need, including: Visual Studio IDE, WinDBG for kernel mode debug, msvsmon for user mode debug.

## Build viogpu3d (KMD)
- This is the kernel mode driver under windows WDDM architecture.
- Open the vs solution `virtio-gpu-win.sln` under `./build/`, select the correct build configuration, such as `Release/x64`.
- Then build the `viogpu3d` project, it will generate `viogpu3d.sys` as KMD, and `viogpu3d.inf` as windows driver install file.

## Build d3d10umd (UMD)
- This is the user mode driver under windows WDDM & DirectX architecture.
- Cause many .c & .h files are generated by python script in mesa project, so we need run the bat script `./build/d3d10umd/gen-mesa-file.bat` firstly.
- Open the vs solution `virtio-gpu-win.sln` under `./build/`, select the correct build configuration, such as `Release/x64`.
- Then build the `d3d10umd` project, it will generate `d3d10umd.dll` as UMD.
